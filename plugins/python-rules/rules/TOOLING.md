# Python Tooling

## uv
- Use `uv` for all Python project management
- Use `uvx` to execute third-party Python tools
- Use `uv_build` as the build backend in pyproject.toml instead of hatchling. 

## Other
- Use ruff for formatting
- Use basedpyright for type checking and linting
- Use `ty` and `pyrefly` as secondary type checkers and linters
